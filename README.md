> # OperPageLes [![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
> Пользовательская система, предоставляемая удобное взаимодействие с Windows.<br>
Даёт возможность управлять открытием каталогов, файлов или ссылок через собственно-разработанный интерпретатор, так и с помощью интерфейса системы.<br>
Представляет собой приложение в котором используются страницы для переключения между управляемыми средствами.<br>
Каждая страница представляется как открыты экземпляр приложения - Страничное приложение.<br>
Программа разрабатывается независимыми разработчиками, энтузиастами своего дела.<br>
Участие в разработке представлено в программе и показано как благодарности за текущую разработку.<br>
Текущий функционал приложения основан на 4 встроенных станичных приложений которые реализуют основной функционал системы.<br>
> + Обработка запросов консоли;
> + Сохранение и представление запросов, иных объектов взаимодействия;
> + Передача данными через Интернет;
> + _Визуализация веб-страниц;_
> ## Безопастность
> Безопастность обеспечивается с помощью алгоритма валидации ключей к конкретному пользователю.<br>
Этот алгоритм обеспечивает свою уникальность и предоставляет доступ исключительно для устройства, которое активирует продукт.<br>
Данный алгоритм безопасности не является публичным.<br>
> ## Технологии
> В системе используются такие технологии как:<br>
> + Самостоятельно разработанная библиотека интерфейса, которая предоставляет приятный визуальный вид системе.<br>
> Удобный и защищённый функционал, он предоставляет удобное взаимодействие с объектами, обеспечивает их гибкость управления.<br>
([InterfaceELement](https://github.com/Lisyaka46/IEL "Библиотека интерфейса"))
> + Разработка интерпретатора для обеспечения гибкости управления доступом и функциями программы.<br>
([InterpreterCommand*](https://github.com/Lisyaka46/InterpreterCommand "Библиотека интерпретатора команд"))
> ## Интерфейс
> Интерфейс программы разработан на основе собственных объектах интерфейса и тех, которые предоставляет ([InterfaceELement](https://github.com/Lisyaka46/IEL "библиотека интерфейса")).
> ## Платформы
> Данная система расширяет использование системы **Windows** и в следствии предоставляется исключительно для платформы Windows.<br>
WPF XAML C#<br>
