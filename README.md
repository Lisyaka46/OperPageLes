# AAC20

AAC20 - это программа для упрощения взаимодействия с windows.

Программа реализует 3 типа команд:
- Консольные
- Голосовые
- Пользовательские

Консольные комманды - команды, встроенные в программу, неизменяемые

Голосовые команды - команды, встроенные в программу, неизменяемые с возможностью включения/отключения

Пользовательские команды - команды, создаваемые пользователем. Могут содержать в себе список 
консольных команд (скрипты), иметь голосовые фразы для выполнения голосовой командой.

Каждая команда имеет описание, пользовательские команды по желанию создателя.
