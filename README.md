# OperPageLes [![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![Подписаться на канал](https://img.shields.io/badge/Telegram-Oper_Page_les-2CA5E0?style=for-the-badge&logo=telegram)](https://t.me/OperPageLes)
<br>Пользовательская система, которая предоставляет доступ к управлению данными через приложение.<br>
Данные представленны в виде страничных приложений которые могут быть установленны в систему.<br>
Некоторые функции предустановлены и также являются отдельными приложениями в системе.<br>
Работа с данными и их отображение реализовано с помощью [**API**](https://github.com/Lisyaka46/OperPageLesAPI)
Присутствуют настройки системы реализованные на основе категорий и параметров.
